\section{Introduction}
Virtual unwrapping needs surfaces that stay on one papyrus sheet. In densely
packed CT volumes, a few erroneous voxels can connect neighboring layers;
removing those voxels after binary segmentation requires recovering which
sheet they belong to. Touching sheets remain a difficulty in the Kaggle
winner's account~\cite{vesuviuswinner}. This motivates predicting individual
sheet geometry together with a representation of sheet identity.

Our central idea is to use \emph{one latent code for reconstruction and
instance discovery}. A denoising autoencoder learns a compact representation
of individual sheets. Given CT and one or more points, a transformer regresses
that representation with MSE. The decoded code reconstructs a sheet; distances
between codes group automatically sampled foreground points. For a $320^3$
crop, prompt-dependent prediction operates on only $10^3$ spatial sites.
Dense sheet decoding is required only for retained instance hypotheses.

We contribute (i) a point-conditioned sheet representation that couples a
learned shape prior with latent identity supervision; (ii) an automatic
seed--code--cluster--decode procedure that shares CT computation; and
(iii) an evaluation separating raw sheet topology, automatic instance
recovery, and topology changes introduced by annotation-ignore erasure.
Large independently flattened surfaces expose downstream coverage and drift.
Topology preservation is empirical: neither the architecture nor its losses
guarantee it, and automatic segmentation does not yet exceed the winner's
combined score.

\paragraph{Relation to prior work.}
ACNN learns anatomical representations to regularize image analysis
\cite{oktay2017acnn}; GSPN reconstructs shape proposals for point-cloud
instances~\cite{yi2019gspn}. Point-SAM studies promptable 3D point-cloud
segmentation~\cite{zhou2024pointsam}. PLatS applies a shared reconstruction
and identity code to thin volumetric sheets, with clustering before dense
decoding. Betti matching provides spatially matched topology losses and
metrics~\cite{stucki2022betti}; here it is used for evaluation, while the
sheet prior is learned without an explicit topology loss. These connections
motivate the design; they are not matched baseline comparisons.
