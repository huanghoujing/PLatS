PLatS learns a sheet representation, then learns to predict it from CT and
points (Fig.~\ref{fig:trainingoverview}). At inference, the same representation
groups foreground seeds and reconstructs individual sheets.

\subsection{Stage 1: learn the sheet AE}
Let $S$ be a clean binary sheet mask and $\widetilde S$ a corrupted version.
The encoder $E$ maps it to a latent code $z$, and the occupancy decoder $D$
reconstructs a probability map $Q$:
\begin{equation}
 z=E(\widetilde S),\qquad Q=\sigmoid(D(z)).
 \label{eq:aesimple}
\end{equation}
Here $\sigmoid$ is the sigmoid function and $D$ includes the final occupancy
head. There are no encoder--decoder skip connections: reconstruction must
pass through $z$. Intermediate occupancy heads predict $Q^{(a)}$, where $a$
indexes decoder stages. A sibling dense head predicts unsigned sheet distance
$U$; a coordinate-query head $h(z,q)$ predicts distance at location $q$.

Final and intermediate occupancy heads use binary cross-entropy (BCE) and
soft Dice losses against the clean sheet. Dense and query distances use
Smooth L1 losses against GT distance targets. A cosine-margin penalty repels
codes of different sheets; spatial penalties suppress foreground outside the
sheet and at the crop border. All AE modules train in this stage and are
then frozen. The bottleneck \emph{empirically favors valid sheet topology},
without a mathematical guarantee or an explicit topology loss.

\subsection{Stage 2: learn point-to-latent prediction}
For CT crop $X$ and positive point set $P$, the image encoder and context
blocks $C$ produce shared features $F$. The point transformer and code heads
$T$ predict a normalized code $\widehat{\bar z}$:
\begin{align}
 F&=C(X),\qquad \bar z=\mathcal N(E(S)),\nonumber\\
 \widehat{\bar z}&=T(F,P),\qquad
 \mathcal L_{\rm code}=\mse(\widehat{\bar z},\bar z).
 \label{eq:predictsimple}
\end{align}
$\bar z$ is the frozen teacher target; $\mathcal N$ is fixed channel normalization
estimated from training-sheet AE codes. MSE averages over all code elements.
Intermediate code heads receive the same target. A same-sheet loss pulls
predictions from different prompt sets toward their mean; a different-sheet
MSE-margin loss separates codes within the same CT crop.

The co-trained binary decoder $B$ predicts union probability
$V=\sigmoid(B(F))$. BCE and Dice supervise $V$ against the GT sheet union
$Y$ on annotated voxels. This stage updates $C$, $T$ and $B$ while the AE
stays frozen. Its base objective needs no full-resolution sheet decoding:
prompt-dependent prediction and supervision act on the compact latent grid.

\subsection{Inference: cluster codes, then decode sheets}
Compute $F$ once and sample seeds from the binary branch's foreground.
Predict a code for each seed and cluster using full-code MSE. For each retained
cluster, combine consistent multi-point code predictions and decode a sheet:
\begin{equation}
 \widehat S=\mathbf1[\sigmoid(D(\mathcal N^{-1}(\widehat{\bar z})))\ge\tau].
 \label{eq:inferencedecode}
\end{equation}
$\widehat S$ is the binary sheet mask, $\mathbf1$ the indicator function,
$\tau$ a probability threshold, and $\mathcal N^{-1}$ reverses normalization.
Unstable clusters are discarded. Duplicate handling, component cleanup and
probability-based overlap resolution produce final instance IDs.
Sharing CT features and clustering before decoding avoids reconstructing
a mask for every seed (Fig.~\ref{fig:inference}). Dimensions, loss weights,
sampling and cleanup are detailed in Supplementary.
